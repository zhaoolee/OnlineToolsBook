把图片转成 Base64 Data URI, 最常见的用途是把图片**内联进网页或邮件模板**, 避免额外的网络请求, 也方便通过 API 直接传输图像数据。

在线直达地址: [https://image2base64.com/](https://image2base64.com/)

## 为什么用纯前端的方式?

很多在线工具会把你的图片**上传到服务器**再处理, 对于包含敏感内容的图片并不安全。

[image2base64.com](https://image2base64.com/) 使用浏览器本地计算, **图片不会离开你的设备**, 转换在本地秒级完成, 兼顾隐私与速度。

支持常见格式互转: 图片转 Base64, 以及把 Base64 反向解码为图片 (jpg / png / gif / svg / webp 等)。

## 小结

如果你需要把图片转成 Base64, 又不想把图片传到别人的服务器, image2base64.com 是一个简洁、隐私优先的选择。
